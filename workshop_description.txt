[h1]Athena Remastered — Real-Time Tactical 2nd Screen Live Map[/h1]

A faithful remaster of Bus's original Athena — stream your Arma 3 mission to a second screen in real time. Works on any browser, tablet, or phone on your local network.


[hr][/hr]

[h1]Features[/h1]

[list]
[*] [b]Live Force and Faction Tracking[/b] — All visible WEST/EAST/GUER/CIV units, vehicles, and groups rendered in real time (not limited to Blue-Force)
[*] [b]Full Terrain Rendering[/b] — Roads, forests, coastlines, contour lines, buildings, and named locations exported directly from the game engine
[*] [b]Multiple Map Styles[/b] — Switch between 2D Topographic, Ground Heatmap, and Pilot Heatmap views
[*] [b]NATO APP-6 Symbology[/b] — Group markers with proper echelon indicators
[*] [b]Vehicle Recognition[/b] — The classic Athena vehicle silhouettes for tanks, APCs, helicopters, planes, boats, artillery, drones, static weapons, and more
[*] [b]I-TGT Target Capture[/b] — Press T or the middle mouse button (SAVE TGT on a tablet) to store map positions as targets
[*] [b]Tablet Layout[/b] — Collapsible sidebars and a layout made for tablets and phones
[*] [b]Role-Specific Unit Icons[/b] — Infantry, medic, officer, engineer, recon, MG, AT, and more
[*] [b]Active Lazes[/b] — Live laser designation points visible to all connected Athena clients
[*] [b]Projectile Tracking[/b] — Predicted ordnance paths with live ETA labels for major launches
[*] [b]Follow Active Player[/b] — Optional auto-follow on the currently controlled player unit
[*] [b]Forest + Trees Layer Controls[/b] — Independent toggles for forest overlay and tree rendering
[*] [b]Coordinate Readouts[/b] — Location X/Y and live mouse-position X/Y on the map
[*] [b]Real-Time Event Feed[/b] — Live kill feed and shot tracking
[*] [b]ORBAT Panel[/b] — Order of Battle view showing all groups organized by faction
[*] [b]Multi-Device Support[/b] — Connect multiple browsers, tablets, or phones to a single session
[*] [b]Server Admin Controls[/b] — Mission makers can toggle visibility of EAST/GUER/CIV sides via mission parameters
[*] [b]Self-Contained Server EXE[/b] — Embedded .NET 9 runtime, no separate runtime install needed
[*] [b]Crash Logs[/b] — Built-in logging to help diagnose startup/runtime failures
[/list]


[hr][/hr]

[h1]How It Works[/h1]

The mod's scripts collect mission data in Arma 3 and send it through a small extension to a local server, which streams it live to every browser on your network.

[code]
Arma 3 (mod) → Local Server → Your Browser / Tablet
[/code]

No external servers. No cloud. Everything stays on your machine or local network.

[hr][/hr]

[h1]Quick Start[/h1]

[olist]
[*] [b]Subscribe[/b] to this Workshop item
[*] [b]Open the server folder:[/b] [b]C:\Program Files (x86)\Steam\steamapps\common\Arma 3\!Workshop\@Athena Remastered\Server[/b]
[*] [b]Run the server:[/b] Start [b]AthenaRemastered.Server.exe[/b]
[*] [b]Open your browser:[/b] Go to [url=http://localhost:5000]http://localhost:5000[/url]
[*] [b]Launch Arma 3[/b] with the mod enabled
[*] [b]Start a mission[/b] — the map populates automatically!
[/olist]

[b]BattlEye:[/b] the extension DLL is not allowlisted. Start Arma with [b]-noBE[/b] (singleplayer / LAN / servers without BattlEye).

[b]Do not combine with Bus's original Athena mod:[/b] load either [i]Athena - An Arma 2nd Screen Application[/i] (for Bus's Athena Desktop / Athena Web 2) or Athena Remastered, not both at the same time. They share an internal addon name and get in each other's way.

[b]If you do not see the !Workshop folder:[/b]
[list]
[*] Open File Explorer
[*] Windows 11: [b]View[/b] → [b]Show[/b] → [b]Hidden items[/b]
[*] Windows 10: [b]View[/b] → enable [b]Hidden items[/b]
[*] If needed, open [b]View[/b] → [b]Options[/b] → [b]View[/b], then choose [b]Show hidden files, folders, and drives[/b]
[/list]

[b]On other devices (tablet, phone):[/b] Open [i]http://<your-pc-ip>:5000[/i] from any device on the same network.

The server is fully self-contained — [b]no .NET runtime or Node.js required[/b].

Athena Remastered works on [b]every Arma 3 map[/b] — vanilla or modded. Terrain data (roads, forests, locations, contours) is exported automatically when you first load a map and cached for future sessions.

[h1]Server Admin Notes[/h1]

[h2]Public Key (BIS Signature Verification)[/h2]

This mod ships with a signed PBO and a public key for server signature verification. To allow Athena Remastered on your server:

[olist]
[*] Navigate to the mod's [b]keys[/b] folder: [b]@AthenaRemastered\keys\[/b]
[*] Copy [b]AthenaRemasteredKey.bikey[/b] into your server's [b]Keys[/b] folder (next to your server executable)
[*] Ensure [b]verifySignatures = 2;[/b] is set in your server config — Athena's PBO will pass verification
[/olist]

The key file is also available in the mod's Workshop folder after subscribing.

[h2]Side Visibility Controls[/h2]

Mission makers can control what sides are visible to Athena through mission parameters in [b]description.ext[/b]:
[list]
[*] Show/hide EAST forces
[*] Show/hide Guerrilla forces
[*] Show/hide Civilian units
[/list]

These settings are pushed automatically from the mission to all connected browsers.
