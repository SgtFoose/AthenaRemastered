# Athena Remastered v1.1.6 Preview

This page tracks current v1.1.6 preview progress.

Status: work in progress (not final release).

## Active Lazes and Projectile Tracking

Core combat-awareness features remain in this preview:

- Active Lazes for real-time designation awareness.
- Projectile Tracking for in-flight path awareness.

![Athena Remastered Active Lazes](../Images/Athena%20Remastered%20Active%20Lazes.png)
![Athena Remastered Active Lazes and Projectile Tracking](../Images/Athena%20Remastered%20Active%20Lazes%20and%20Projectile%20Tracking.png)

## Implemented UI and Map Improvements

The following fixes and quality improvements are now implemented in preview testing:

- Toggle buttons improved and expanded for better layer control (including separated map-layer controls).
- Contours rendering fixed for consistent visibility.
- Location entries now expose X and Y coordinates for easier referencing.
- Mouse X/Y coordinates are shown in the bottom-right corner for quick map callouts.
- Map style modes Ground and Pilot are implemented and available.
- Objects rendering improvements are implemented.
