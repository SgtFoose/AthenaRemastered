# Athena Remastered v1.1.6 Feature Overview

This page summarizes the major capabilities and fixes delivered in v1.1.6.

## Feature Highlights

- Embedded .NET 9 runtime in AthenaRemastered.Server.exe (self-contained server deployment)
- Added startup/runtime logging for faster diagnosis and support
- Added Forest Renders with dedicated Forest Overlay and Trees toggles
- Added Projectile Tracking with predicted trajectories and ETA labels
- Added Active Lazing map markers for live laser designation awareness
- Added Follow Active Player mode
- Added X/Y coordinates for locations
- Added X/Y coordinates for live mouse position on map

## Fixes and Stability Improvements

- Fixed iPad/tablet export status scaling issues
- Fixed both map style modes: Ground and Pilot
- Fixed contour rendering consistency
- Fixed Roads toggle so it no longer toggles Objects and Structures
- Updated render status fields for clearer progress state
- Fixed waypoints clearing after a unit dies
- Fixed icon for steerable parachutes

## BattlEye Status

- BattlEye whitelist filing has been submitted for the DLL-based path
- Workaround is prepared if allowlisting is delayed or not approved
