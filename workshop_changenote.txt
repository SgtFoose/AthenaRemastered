v1.2.1 - Hotfix: Athena starts again in missions + performance

IMPORTANT: v1.2.0 did not start in missions. Please make sure Steam has updated the mod, and restart the server (Server\AthenaRemastered.Server.exe).

Fixes
- Athena starts again in every mission (v1.2.0 thought the mission was still the main menu)
- No more FPS loss: live updates now run 4 times per second instead of every frame (tested with 66 units and 15 vehicles: same FPS as without Athena)
- Exporting a large map no longer freezes the game
- Tablets: projectile paths and the Fire Control panel now show live, also when the tablet clock is a few seconds off
- Tablets: the map reconnects by itself after the screen was off (no F5 needed)
- One Recent Shots entry per shot
- Crew labels show the real seat (D: driver, G: gunner, C: commander)
- M5 Sandstorm / artillery: follow-up shots use the real impact point and time of flight
- Per-shot debug logging is off by default

Thanks to Mrakos for the performance analysis.

Note
- Do not load Bus's original "Athena - An Arma 2nd Screen Application" mod together with Athena Remastered. Both use the same internal name and get in each other's way.

BattlEye
- The extension DLL is unchanged and not allowlisted: use -noBE for singleplayer / LAN
